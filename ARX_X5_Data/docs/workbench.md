# 可选引导工作台（8765）

设备电脑上的本地网页，中文开工引导、按条录制、本地保存记录与遥操复位。Python 3.10+（Linux），无需安装第三方依赖。

## 运行

在本目录打开终端：

```bash
python3 server.py --demo
```

浏览器打开 http://127.0.0.1:8765 。**演示模式只写示例 JSON，不连接设备**，文件在 `.demo-data/`。每次显式重启演示服务会重置演示流程记录，已有示例文件保留。

设备模式：

```bash
cp config.example.json config.local.json
# 按 docs/接入说明.md 填写配置并实现现有程序的适配脚本
python3 server.py
```

可用 `--port 8766` 指定端口，`--config /absolute/path/config.json` 指定配置。仅绑定 `127.0.0.1`，浏览器也请使用此地址。终端 Ctrl+C 仅停止网页服务，不代替设备收工操作，不会自动停止遥操或录制。

未配置时仍可阅读页面，真实设备操作被禁用。启动服务不会自动执行设备命令；页面定期调用只读 status 接口核对状态。相同模式只允许一个服务实例，避免多进程重复控制。

## 交付内容

- `/`：开工检查、试采、正式采集、保存结果、人工遥操复位与记录列表。
- `/guide`：可打印的一页速查教程，用浏览器打印为 PDF。
- `config.example.json`：现场信息及四项适配命令模板。
- [现场接入说明](接入说明.md)：命令返回协议、恢复要求和现场验收清单。
- `tests/test_workbench.py`：状态、文件凭据、防重复、异常和同源访问检查。

## 行为

开关和四路 CAN 为人工确认；点击“连接 CAN Doctor”在工作台内打开原网页，完成 Detect Devices / Start All。原网页只在首次打开时载入，状态轮询及返回工作台不会重载它。遥操启动与录制分别控制。每条录制保存完成后进入复位，操作员用机械臂复位并确认，然后显式开始下一条。复位按钮不执行机器人动作。试采必须人工核对文件，确认后才切换为正式采集；试采不计入正式条数。

操作结果以适配器返回为准。保存必须有匹配编号、绝对路径、目录范围内的非空内容，并由录制器确认文件写盘完成，才会计入本地记录。校验与转换在现有独立后台队列执行，状态单独展示，不阻塞下一条采集。异常时不盲目重发命令，通过只读状态与保存凭据核对。服务重启会清除开工人工确认，保留正式流程记录并重新核对设备。

## 已接入本机 CAN Doctor

在 `config.local.json` 中配置现场官方程序 `/absolute/path/to/ARX_CAN_doctor` 与 `http://127.0.0.1:8000`。工作台的“连接 CAN Doctor”会检查网页服务，未运行时按固定命令启动；数采员不需开终端或输入地址。只打开网页，不自动触发 Detect/Start All。返回工作台保留内嵌页面；若浏览器不支持嵌入，可点击“新窗口打开”。

演示模式仅模拟录制和遥操；内嵌的 CAN Doctor 是真实官方程序，其按钮会影响实际 CAN 设备。


## 真实试采

设备模式下“开始试采”已连接当前 8080 录制器，复用三路相机和遥操反馈。结束后仅等待本条文件写盘完成即可进入场景复位；完整性校验与转换在后台继续。试采目录单独标记；正式条数不包含试采。历史软件测试覆盖原有流程、控制接口去重、错误条目停止拒绝和保存校验状态。


## 收工结束遥操

顶部“结束遥操”按钮发送正常退出请求。录制和写盘期间不可用；请先保存，再手动回正双臂并稳定，点击退出。实际进程退出后才显示“遥操已结束”。未满足条件时提示人工处理后再次点击，不自动回零或强制结束。历史软件测试覆盖退出条件拒绝、录制中阻止结束、保存记录保留与重新启动阶段恢复。


## 连续采集

结束并保存 → 本条文件写盘完成 → 遥操复位 → 下一条。后台校验和转换可与后续采集并行；工作台新增后台处理汇总，采集记录逐条显示进度和失败原因。本地已保存数量与校验通过数量分开显示，避免把待处理数据误认为已通过校验。后台任务失败保留原始文件，不中断当前采集。

## 删除本条

录制中、最近保存卡片、采集记录行都提供“删除本条”。录制中会结束并作废本条；已保存条目采用可恢复删除，原始文件保留，计数剔除，后台处理和后续导出排除。在记录中点击“恢复本条”可恢复已保存的完整条目。已作废或不完整的片段不能恢复为有效数据。

## 数据浏览与人工审核

打开 `http://127.0.0.1:8765/browse`，或点击侧栏“数据浏览与审核”。浏览器读取 `save_dir` 下所有真实任务的 Episode，不依赖本次工作台的保存记录；模拟数据、转换副本不重复列出。支持任务、编号、人工审核和数据状态筛选，作废/删除条目默认隐藏。

三路相机共用播放/暂停、倍速、帧位置滑块和逐帧按钮，空格播放/暂停、左右方向键逐帧。任一路缓冲时全部暂停；缺视频或解码失败有明确提示。回放按视频帧索引对齐，原始采样网格缺失不会被补造，详情显示内部缺帧、最大采样间隔、三相机时间跨度、相机时刻偏差和向量完整性。浏览器视频不是硬实时显示，深度排查请使用 Rerun。

人工结论为“未审核 / 通过 / 不通过 / 需复核”，需要审核人；不通过、需复核需要备注。每次保存记录审核人、时间、备注、版本和历史，写入该 Episode 的 `.workbench-review.json`。采用版本检查避免多窗口覆盖，审核不会触发删除或设备控制，也不会把原有后台 `complete` 当成人工通过。“保存并查看下一条未审核”沿当前筛选继续审核。离开有未保存修改的条目时提示。

Rerun 集成使用当前 LeRobot 官方 `lerobot.scripts.lerobot_dataset_viz`，读取转换后的本地数据，生成 `.rrd` 后可下载或在本机 Rerun 网页查看器打开，包含相机、状态和动作。任务异步执行并显示进度状态、错误和重试入口；生成结果缓存在 `.runtime/<模式>/visualization/`，不会自动启动机器人。默认解释器是 `.runtime/lerobot-main-venv/bin/python`，可通过 `visualization_python` 指定安装了当前 LeRobot 和 `rerun-sdk` 的解释器。后台导出使用离线模式，未转换完成的条目不可生成。
