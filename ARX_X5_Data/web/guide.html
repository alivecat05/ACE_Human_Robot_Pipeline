ARX / OPERATOR QUICK GUIDE

数采员 · 一页操作速查

开工检查一次，之后按条循环采集。浏览器打印可保存为 PDF。

遥操一直开着。只录正式任务，复位时不录制。

01 · 开工准备

按工作台内的现场说明打开开关 → 点击工作台“连接 CAN Doctor”，在内嵌页面操作 → 点击 检测设备 / Detect Devices → 核对四路 CAN → 执行 一键启动 / Start All → 对照正常状态逐项勾选 → 点击“确认开工检查”。

成功标志：四路均符合现场配置的正常状态。工作台勾选仅为人工确认。

失败时：停在当前步骤，核对现场接线与页面提示；无法确认时联系现场负责人。

02 · 启动遥操与试采

点击“核对设备状态”；若遥操尚未运行，点击“启动遥操”。显示“运行中”后，点击“开始试采”。完成任务后点击“结束并保存”。

成功标志：显示本条编号与真实文件位置；操作员在设备电脑核对文件可读、内容及时长，再点击“文件已核对，进入正式采集”。

失败时：查看错误提示，核对现有程序，不要连续重复启动或覆盖已有文件。

03 · 每条循环：录制 → 保存 → 复位

① 开始本条录制：看到“录制中”及计时后，再进行任务操作。
② 结束并保存：等待本条文件写盘完成，出现本条编号及本地路径。校验和转换在后台继续，无需等待后处理即可复位。
③ 遥操复位：保持遥操运行，用机械臂把场景恢复好。此时不录制。
④ 场景已复位：点击确认，回到等待状态；再点击“开始本条录制”录下一条。后台处理进度与失败原因可在“本地采集记录”查看。

04 · 删除、异常与收工

删除本条：录制中点击“删除本条”会结束并作废当前条；已保存后可在最近保存卡片或采集记录中删除。原始文件保留，已保存的完整条目可点“恢复本条”。已删除条目不计入有效数量。

后台处理失败：原始文件保留，查看采集记录中的原因，可继续采集后续条目。
写盘失败／录制中断：保留文件与报错信息，先核对现有程序，再点击“重新核对状态”。未取得保存凭据的条目不计入完成数量。
网页断线：检查本地服务，恢复连接后核对设备真实状态。关闭网页不等于停止录制或遥操。
收工：先结束当前录制并确认保存 → 用示教臂手动回正双臂并稳定 → 点击顶部“结束遥操” → 确认显示“遥操已结束”。未退出时按提示处理，再次点击。然后按现场已核实顺序断电。

具体开关位置、CAN 对应关系、正常状态、保存目录与收工顺序，请以工作台的现场配置为准。显示“待填写”的项目必须在独立作业前补齐。
