连接 CAN Doctor

跟着这三步操作

  1. 点击 检测设备 / Detect Devices

    查看识别到的 USB-CAN 设备，对照现场四路接口。

  2. 核对四路接口

    对照下方设备名称与正常标志，确认每一路。

  3. 点击 一键启动 / Start All

    四路均符合正常标志后，返回工作台逐项确认，再启动遥操。
